## Modification Protocol

1. Brand strategy changes require explicit authorization from the Business Owner.
2. Minor edits (typo fixes, link updates) increase patch version (e.g., `v2.0.1`).
3. Major strategic changes require a new minor/major version release directory (e.g., `docs/brand/v2.1/`).
