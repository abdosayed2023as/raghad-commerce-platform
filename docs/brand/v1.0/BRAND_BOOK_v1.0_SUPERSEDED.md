**Effective Date**: August 2, 2026

**Brand Name**: عالم رغد | Raghad World  
**Target Market**: Egypt (جمهورية مصر العربية)

## 1. رؤية البراند والهوية الاستراتيجية (Brand Strategy)

### 1.1 اسم البراند والتموضع (Brand Positioning)
- **الاسم الرسمي**: **عالم رغد | Raghad World**
- **الدومين المستهدف**: `raghadworld.com` / `raghadworld.eg` (توجيه `raghadkids.com` تلقائياً للهوية الجديدة).
- **الرسالة والتموضع (Tagline & Positioning)**:  
  > **"عالم رغد — لكل ما يكمل جمال بيتك وعائلتك"**

### 1.2 شخصية البراند (Brand Personality Archetype)
- **العمر الذهني للشخصية**: فتاة في الـ 28 من عمرها.
- **الصفات الأساسية**: هادئة، ذكية، ذات ذوق رفيع، تهتم بالتفاصيل، تقدم النصيحة والراحة للأمهات والعرائس دون فرض رأي أو إزعاج.
- **نبرة الصوت (Brand Voice)**:
  - لا نستخدم صيغ الأمر المباشرة القاسية ("اشترِ الآن").
  - نستخدم صيغ المساعدة والاهتمام ("دعنا نساعدك في اختيار الأنسب لطفلك وبيتك").
  - نركز على **الفوائد وراحة البال** وليس فقط ميزات المنتج المجردة.

### 1.3 القيم الجوهرية (Brand Core Values)
1. **الثقة والأمان**: إزالة كافة المخاوف النفسية لدى المستهلك المصري قبل الشراء.
2. **الأناقة الدافئة**: تصميم عصري وفاخر يجمع بين البساطة والرقي.
3. **الجودة والاهتمام**: انتقاء منتجات ممتازة تليق بالأسرة والعروسة.
4. **الراحة وسهولة التجربة**: رحلة تسوق سلسة لا تتعدى 3 ضغطات على الهاتف.

## 2. ركائز البراند الثلاثة (House of Lifestyle Brands)

يعتمد متجر **عالم رغد | Raghad World** على استراتيجية بيت البراندات الموحد المكون من 3 قطاعات متناغمة:

```text
                                  +------------------------------------+
                                  |     عالم رغد | Raghad World       |
                                  +-----------------+------------------+
                                                    |
         +------------------------------------------+------------------------------------------+
         |                                          |                                          |
         v                                          v                                          v
+------------------+                       +------------------+                       +------------------+
| 👶 رغد كيدز      |                       | 🏠 رغد هوم       |                       | 👰 رغد العروسة   |
|  (Raghad Kids)   |                       |  (Raghad Home)   |                       |  (Raghad Bridal) |
+------------------+                       +------------------+                       +------------------+
| - أطقم العناية   |                       | - منظمات المطبخ  |                       | - مفروشات فاخرة  |
| - ملابس البيبي   |                       | - ديكورات عصرية  |                       | - أطقم الفوط     |
| - مستلزمات الرعاية|                      | - أدوات المنزل   |                       | - تجهيزات العروسة|
+------------------+                       +------------------+                       +------------------+
```

### 2.1 قطاع رغد كيدز (Raghad Kids 👶)
- **المنتج البطل (Hero Product)**: **أطقم العناية الشاملة بالطفل والبيبي** (المنتج الأكثر مبيعاً).
- **التصنيفات الفرعية**: أطقم العناية، ملابس البيبي، مستلزمات الرعاية والسلامة، الألعاب التعليمية.

### 2.2 قطاع رغد هوم (Raghad Home 🏠)
- **التصنيفات الفرعية**: منظمات المطبخ والثلاجة، الديكورات الدافئة، أدوات ومستلزمات تنظيم المنزل العصري.

### 2.3 قطاع رغد العروسة (Raghad Bridal 👰)
- **التصنيفات الفرعية**: أطقم المفروشات واللحاف الفاخر، أطقم الفوط الفندقية، مستلزمات وتجهيزات العروسة الخاصة.

## 3. الهيكل التجاري وقواعد التحويل (CRO & Commercial Strategy)

### 3.1 السوق والفئة السعرية
- **السوق المستهدف**: جمهورية مصر العربية (كافة المحافظات).
- **الشحن**: توصيل سريع لجميع المحافظات.
- **الفئة السعرية (Pricing Tier)**: Mid-Range إلى Premium (أسعار عادلة تناسب القيمة المدركة الفاخرة للمنتجات).

### 3.2 سياسة الثقة الأولى: "المعاينة عند الاستلام" 🛡️
- **الهدف النفسي**: القضاء التام على الخوف الأكبر لدى المستهلك المصري (خوف اختلاف المنتج عن الصور).
- **التطبيق**: إبراز شارة **"حق المعاينة الكاملة والفتح قبل الدفع"** في:
  1. شريط الإعلانات العلوي (Announcement Bar).
  2. تحت زر الشراء الرئيسي في صفحة المنتج (PDP).
  3. الفوتر وشريط الضمان.

### 3.3 سياسة العربون الشفاف لتقليل المرتجعات (RTO Control) 💳
- **المنتجات المستهدفة**: المنتجات الفاخرة مرتفعة السعر (أكثر من 1500 ج.م).
- **الرسالة الشفافة**: "هذا المنتج يتطلب عربون جدية بسيط (50–100 ج.م) لضمان الشحن، والمتبقي يُدفع عند الاستلام بعد المعاينة."
- **الهدف التجاري**: تقليل نسبة الطلبات الوهمية والمرتجعات (Return To Origin) دون ترهيب العميل.

### 3.4 رفع متوسط قيمة الطلب (AOV Boosters) 🚀
- **شريط تقدم الشحن المجاني (Free Shipping Progress Bar)**: يظهر داخل السلة الجانبية (Cart Drawer) بشكل تفاعلي (مثال: *"باقي لك 150 ج.م للحصول على شحن مجاني"*).

## 4. نظام الهوية البصرية (Visual Design System)

### 4.1 اتجاه التصميم (Design Direction)
**Modern High-Contrast Luxury / Soft Warm Elegance**: تباين عالي فاخر مع خلفيات ناصعة ونظيفة، حواف دائرية ناعمة، مساحات تنفس واسعة، وظلال خفيفة ناعمة.

### 4.2 لوحة الألوان الرسمية (Color Palette)

| اسم اللون | الرمز الهكس (Hex) | الاستخدام والتطبيقات |
| :--- | :---: | :--- |
| **Primary (الوردي الفاخر الدافئ)** | `#D48C80` | اللون الرئيسي للبراند، التبويبات البارزة، شارات العناية. |
| **Secondary (الكحلي الملكي الداكن)** | `#2C2230` | العناوين الرئيسية، النصوص، الأزرار التفاعلية، الفوتر. |
| **Background (الابيض النقي)** | `#FFFFFF` | خلفية المتجر الرئيسية لضمان وضوح صور المنتجات. |
| **Surface (الأبيض العاجي الناعم)** | `#FAFAFA` | خلفية كروت المنتجات والأقسام والظلال. |
| **Success / Trust (الزمردي)** | `#10B981` | شارات المعاينة عند الاستلام والدفع عند التسليم. |
| **Warning / Deposit (الذهبي الدافئ)** | `#F59E0B` | صندوق تنبيه العربون وشارات الخصومات المميزة. |

### 4.3 الخطوط وطباعة النصوص (Typography)
- **الخط العربي الرئيسي**: **Cairo** (بأوزان 500 للنصوص، 700 للعناوين، 800 للأسعار والأزرار).
- **الخط الإنجليزي والأرقام**: **DM Sans** / **Playfair Display**.

### 4.4 العناصر البصرية والحواف (UI Tokens)
- **Border Radius (الحواف)**: 16px لكروت المنتجات، 30px للأزرار وشارات التنبيه (Soft Rounding).
- **Shadows (الظلال)**: `0 4px 20px rgba(0, 0, 0, 0.05)` ظلال خفيفة ناعمة جداً عند التمرير (Hover Lift Effect).

## 5. مواصفات الـ Custom Theme لمنصة Easy Orders

### 5.1 الهيدر الزجاجي (Header Section)
- شريط إعلانات علوي ثابت: *"الشحن لكافة محافظات مصر 🚛 | المعاينة عند الاستلام 🛡️"*.
- لوجو **عالم رغد | Raghad World** بالمنتصف.
- أيقونات عصرية كروية 48px للبحث، المفضلة، وسلة التسوق مع عداد وردي تفاعلي.
- تبويبات الملاحة الرئيسية للقطاعات الثلاثة: `[👶 رغد كيدز] — [🏠 رغد هوم] — [👰 رغد العروسة]`.

### 5.2 البانر الرئيسي (Hero Section)
- شبكة متوازنة (2-Column Grid): النص والرسالة التسويقية على اليمين مع أزرار الشراء، والصورة المؤطرة لأطقم العناية بالطفل (Hero Product) على اليسار مع بطاقة تقييم عائمة (+10,000 عميلة وثقت بنا).

### 5.3 شبكة المنتجات (Product Grid)
- عرض 4 منتجات بالسطر على الكمبيوتر (Desktop) و 2 منتج على الهاتف (Mobile).
- بطاقات منتجات عصرية تضم: تقييم النجوم الذهبية، السعر قبل وبعد الخصم، مبلغ التوفير، شارة "المعاينة عند الاستلام"، وزر إضافة سريعة للسلة.

### 5.4 صفحة المنتج (Product Detail Page - PDP)
- حاسبة توفير واضحة ("وفرت 150 ج.م").
- صندوق تنبيه العربون الشفاف للمنتجات الفاخرة.
- زر شراء ثابت لأسفل الشاشة على الهاتف (Sticky Add-to-Cart Bar).

### 5.5 السلة الجانبية (Slide-Out Cart Drawer)
- تفتح تلقائياً عند إضافة منتج عبر `eo:cart`.
- تضم شريط تقدم الشحن المجاني ومقترحات إضافة سريعة (Upsell).

### 5.6 الفوتر الفاخر (Footer Section)
- فوتر داكن (#0F172A) مقسم إلى 4 أعمدة يضم: قصة عالم رغد، روابط الأقسام الثلاثة، سياسات المعاينة والعربون والشحن، زر تواصل واتساب سريع، وشارات الدفع.
