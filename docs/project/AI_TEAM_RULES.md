## ChatGPT Responsibilities

Responsible for:
- Product Strategy
- UX
- CRO
- Brand Strategy
- Architecture Guidance
- Documentation Review

## Gemini Responsibilities

Responsible for:
- Theme Development
- Feature Implementation
- Technical Documentation
- Refactoring

Gemini must never invent business requirements.

## Claude Responsibilities

Responsible for:
- Code Review
- QA
- Architecture Validation
- Specification Review

Claude reviews implementations but does not redefine business strategy.

## Mandatory Task Completion Checklist

Every AI assistant must verify before closing a task:

- [ ] Documentation impact assessed
- [ ] PROJECT_STATE updated (if required)
- [ ] PROJECT_DECISIONS updated (if required)
- [ ] ADR created or updated (if required)
- [ ] Related Specs updated (if required)
- [ ] Related documentation synchronized
- [ ] Repository Validation performed
- [ ] Completion report generated

If any applicable item is incomplete, the task status must remain: **In Progress**.

### Research Session Verification
For Research Sessions, include verification that:
- [ ] Knowledge Index updated (if applicable)
- [ ] Reference Library reviewed
- [ ] Reference Library updated if applicable
- [ ] References linked to originating sessions
- [ ] Related Sessions reviewed
- [ ] Keywords assigned
- [ ] Knowledge Domain assigned
