## Definitions

- **Business**: The commercial strategy, goals, and logic driving the project.
- **Brand**: The identity, values, and perception of Raghad World.
- **UX**: User Experience; the overall experience and interaction flow for a customer.
- **UI**: User Interface; the visual components and layouts of the platform.
- **CRO**: Conversion Rate Optimization; strategies to increase the percentage of users who make a purchase.
- **SEO**: Search Engine Optimization; practices to increase organic visibility.
- **RFC**: Request for Comments; a document proposing architectural or process changes.
- **ADR**: Architecture Decision Record; a document capturing an important architectural decision.
- **Spec**: Specification; detailed technical requirements for a feature before implementation.
- **Sprint**: A time-boxed iteration of work.
- **Milestone**: A significant checkpoint or goal in the project timeline.
- **Epic**: A large body of work that can be broken down into specific tasks or specs.
- **Theme**: The complete codebase representing the storefront's appearance and functionality.
- **Section**: A customizable, reusable block of content within the theme.
- **Snippet**: A small, reusable piece of code included within sections or templates.
- **Component**: A self-contained UI element (e.g., button, input field).
- **Template**: The structure defining the layout of a specific page type.
- **Information Architecture**: The structural design and organization of content.
- **User Flow**: The path a user takes to complete a specific task.
- **Product Card**: A UI component displaying a product summary (image, price, title).
- **PDP**: Product Details Page; the page showcasing a single product.
- **PLP**: Product Listing Page; a category or search results page showing multiple products.
- **AOV**: Average Order Value; the average amount spent per checkout.
- **LTV**: Lifetime Value; the total expected revenue from a single customer.
- **Single Source of Truth**: The definitive, undisputed reference (usually the repository documentation).
- **Repository**: The version-controlled storage for all project code and documentation.
- **Documentation**: Written records of decisions, strategies, and specifications.
- **Implementation**: The act of writing code to build a documented specification.
- **Review**: The process of checking code or documents for quality and compliance.
- **QA**: Quality Assurance; the testing phase to verify acceptance criteria are met.
